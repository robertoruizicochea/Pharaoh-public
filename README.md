# Pharaoh

R Shiny app to view a Bitcoin wallet's BRC-20 token balances and tickers using the public bestinslot.xyz BRC-20 API. `Updater. R` refreshes the ticker list.

## Run
1. Install R packages: `shiny`, `DT`, `readr`, `stringr`.
2. In R: `shiny::runApp()`

No API key required. MIT License (see `LICENSE`).
